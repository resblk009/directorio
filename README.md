# directorio
las bases para programar en c++

Ejercicios Básicos de C++

Colección de programas desarrollados en C++ para practicar conceptos fundamentales de programación como entrada y salida de datos, estructuras condicionales, ciclos, operaciones matemáticas, manejo de cadenas y algoritmos básicos. Los ejercicios abarcan desde programas introductorios hasta problemas que requieren mayor lógica de programación.

Requisitos
Compilador C++ (g++, MinGW, Dev-C++, Code::Blocks, Visual Studio, etc.).
Sistema operativo Windows para el correcto funcionamiento de system("pause") y system("cls") utilizados en algunos programas.
Archivos incluidos
1. holamundo.cpp

Muestra el clásico mensaje "Hola Mundo" en pantalla. Es un ejercicio introductorio para familiarizarse con la estructura básica de un programa en C++.

Temas utilizados:

iostream
cout
Función main()
2. par,impar.cpp

Solicita un número entero al usuario y determina si es par o impar utilizando el operador módulo %.

Temas utilizados:

Variables enteras
Condicionales if-else
Operador módulo %
3. cantidad mayor a tres números.cpp

Permite ingresar tres números y determina cuál es el mayor mediante comparaciones lógicas. Incluye repetición mediante un ciclo do-while.

Temas utilizados:

Condicionales anidados
Operadores lógicos
Ciclos do-while
4. promedio de cali.cpp

Calcula el promedio de tres calificaciones ingresadas por el usuario y muestra el resultado con dos decimales. Permite realizar múltiples cálculos.

Temas utilizados:

Variables tipo double
Biblioteca iomanip
Formato de salida con setprecision
Ciclos repetitivos
5. área de cuadrado.cpp

Calcula el área de un cuadrado a partir de la longitud de uno de sus lados. Incluye validación para evitar valores menores o iguales a cero.

Fórmula utilizada:

Área = lado × lado

6. área de un triángulo.cpp

Calcula el área de un triángulo utilizando la base y la altura proporcionadas por el usuario.

Fórmula utilizada:

Área = (base × altura) / 2

7. área de círulo.cpp

Calcula el área de un círculo utilizando el radio ingresado por el usuario. Incluye validación de datos y repetición del cálculo.

Fórmula utilizada:

Área = π × radio²


Constante utilizada:

#define PI 3.1416

8. determina si el número es primo.cpp

Verifica si un número es primo comprobando si tiene divisores distintos de 1 y de sí mismo. Permite realizar múltiples pruebas.

Temas utilizados:

Variables booleanas
Ciclos do-while
Operador módulo
Algoritmos matemáticos básicos
9. calculadora.cpp

Archivo inicial que actualmente muestra un mensaje en pantalla. Puede utilizarse como base para implementar una calculadora con operaciones matemáticas básicas.

10. Untitled1.cpp

Programa de captura de datos personales. Solicita nombre, apellido, teléfono y año de nacimiento para calcular y mostrar la edad del usuario. Permite repetir el proceso varias veces.

Temas utilizados:

string
getline()
Manejo de búfer con cin.ignore()
Cálculos aritméticos
Ciclos do-while
Temas de Programación Cubiertos

Los programas incluidos permiten practicar los siguientes conceptos:

Variables (int, float, double, string)
Entrada y salida de datos (cin, cout)
Operadores aritméticos
Operadores relacionales y lógicos
Condicionales (if, else if, else)
Ciclos (do-while)
Validación de datos
Formato de salida
Manejo de cadenas
Algoritmos matemáticos básicos
Objetivo del Proyecto

Este conjunto de ejercicios tiene como finalidad fortalecer los fundamentos de programación en C++, desarrollando habilidades para resolver problemas mediante estructuras de control, operaciones matemáticas y manipulación básica de datos.
